# Selenium Tesztelés Indítása

## Előkészületek

1. **Győződj meg róla, hogy a szükséges csomagok telepítve vannak:**
   ```sh
   pip install selenium pytest
   ```

2. **Indítsd el az alkalmazásodat (ha szükséges)**
   ```sh
   npm start  # vagy
   yarn start
   ```

## Teszt futtatása

A teszt indításához futtasd az alábbi parancsot:
```sh
python -m pytest test.py
```
